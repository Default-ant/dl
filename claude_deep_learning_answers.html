Purpose of regularization. How L1 and L2 achieve the objective (mathematical intuition). Why L1 acts as a feature selector.
10 M
What is Regularization?

Regularization adds a penalty term to the loss function to reduce model complexity and prevent overfitting. The modified objective is:

L_reg = L_data + λ · Ω(w) where L_data = training loss (e.g., MSE, cross-entropy) Ω(w) = regularization penalty λ = regularization strength (hyperparameter)
L2 Regularization (Ridge / Weight Decay)
Ω(w) = Σ wᵢ² → L_reg = L_data + λ Σ wᵢ² Gradient update: wᵢ ← wᵢ − η [∂L_data/∂wᵢ + 2λwᵢ] Effect: Penalises large weights uniformly. Weights shrink towards zero but NEVER reach exactly zero. Constraint region = sphere (smooth).
L1 Regularization (Lasso)
Ω(w) = Σ |wᵢ| → L_reg = L_data + λ Σ |wᵢ| Sub-gradient update: wᵢ ← wᵢ − η [∂L_data/∂wᵢ + λ·sign(wᵢ)] Effect: Applies a CONSTANT pull towards zero regardless of weight magnitude. Constraint region = diamond (corners on axes).
Why L1 is a Feature Selector

The L1 constraint region is a diamond (rhombus) in 2D. Its corners lie on the coordinate axes. When the elliptical contours of the loss function touch this diamond, they almost always hit a corner, which corresponds to one or more weights being exactly zero.

Geometric intuition: L2 → circle → loss contour touches edge → all weights small but non-zero L1 → diamond → loss contour touches corner → many weights = EXACTLY 0 A weight = 0 means its corresponding feature is eliminated from the model. → L1 automatically performs FEATURE SELECTION.

Q3a
How Transfer Learning improves CNN performance for image classification.
6 M
Concept

Transfer Learning reuses a model trained on a large source dataset (e.g., ImageNet with 1.2M images) and adapts it to a smaller target task. This leverages pre-learned hierarchical features.

Process
Step 1 – Choose a pre-trained base model

Select VGG16, ResNet50, InceptionV3 etc., already trained on ImageNet.

Step 2 – Remove the top classification head

Drop the final fully-connected + softmax layer(s) tuned for ImageNet's 1000 classes.

Step 3 – Freeze early layers (Feature Extraction)

Early layers encode generic patterns (edges, textures, shapes). Freezing means weights are not updated → faster training, avoids overfitting on small datasets.

Step 4 – Add new classification head

Add FC layers matching your number of target classes. Randomly initialise these.

Step 5 – Train (and optionally Fine-tune)

Feature Extraction: Only train the new head.
Fine-tuning: Unfreeze top N layers of base model, retrain end-to-end with a very small learning rate (e.g., 1e-5).

Why It Works
  • Lower layers: edges, blobs, colours – universal features
  • Higher layers: task-specific patterns that can be fine-tuned
  • Needs far less labelled data for the target task
  • Significantly reduces training time and compute cost
Q3b
Explain Normalization. Justify how Batch Normalization makes training faster.
4 M
Normalization

Normalization rescales inputs/activations so they have a consistent distribution, preventing large variations that slow down or destabilise gradient-based learning.

Batch Normalization Algorithm
For a mini-batch B = {x₁, x₂, …, xₘ}: 1. μ_B = (1/m) Σ xᵢ ← batch mean 2. σ²_B = (1/m) Σ (xᵢ − μ_B)² ← batch variance 3. x̂ᵢ = (xᵢ − μ_B) / √(σ²_B + ε) ← normalize 4. yᵢ = γ x̂ᵢ + β ← scale and shift (learned γ, β)
Why It Makes Training Faster
  • Reduces Internal Covariate Shift: The distribution of each layer's input stays stable across batches, so deeper layers don't have to constantly re-adapt.
  • Enables Higher Learning Rates: Normalised inputs prevent gradient explosion, so larger learning rates can be used → faster convergence.
  • Smooth Loss Landscape: BN smooths the optimisation surface, making gradient descent more efficient.
  • Regularisation Effect: The mini-batch statistics add noise, reducing the need for dropout → fewer regularisation techniques needed.

Q5
How Bi-LSTM improves upon Bi-RNN for long-term dependencies. Vanishing gradient problem.
10 M
The Problem: Speech-to-Text with Long Sentences

A Bi-RNN processes the sequence in both forward and backward directions, then concatenates the hidden states. However, for long sequences, gradient information must flow through many time steps.

Vanishing Gradient in Bi-RNN
∂L/∂h₁ = ∂L/∂hₙ × ∏ᵢ ∂hᵢ/∂h_{i-1} = ∂L/∂hₙ × ∏ᵢ (W_hh · diag(f'(zᵢ))) If |eigenvalues of W_hh · diag(f')| < 1 → product → 0 (vanishing) If > 1 → product → ∞ (exploding) tanh derivative ≤ 1 → gradient shrinks multiplicatively with each step → h₁ gets almost ZERO gradient when sequence is long → model fails to capture long-range dependencies
How Bi-LSTM Solves This

LSTM introduces a cell state (cₜ) – a memory highway that carries information with minimal transformation:

LSTM Gates: fₜ = σ(W_f·[hₜ₋₁, xₜ] + b_f) ← Forget gate: what to discard iₜ = σ(W_i·[hₜ₋₁, xₜ] + b_i) ← Input gate: what to add g̃ₜ = tanh(W_c·[hₜ₋₁, xₜ] + b_c) ← Candidate cell state oₜ = σ(W_o·[hₜ₋₁, xₜ] + b_o) ← Output gate Cell state update (key equation): cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ g̃ₜ Hidden state: hₜ = oₜ ⊙ tanh(cₜ) Gradient through cell state: ∂cₜ/∂cₜ₋₁ = fₜ (element-wise, close to 1 for relevant memories) → NO repeated matrix multiplication → gradient preserved!
Bidirectional Architecture
Forward LSTM: h→ₜ processes x₁ → x₂ → … → xₙ Backward LSTM: h←ₜ processes xₙ → xₙ₋₁ → … → x₁ Output: ŷₜ = W·[h→ₜ ; h←ₜ] + b (concatenated) Benefit: Each position has context from BOTH past AND future tokens. For ASR: "The bat flew past the barn" – "bat" needs future context to resolve ambiguity.

PART A
Regularization

Adding a penalty to the loss to reduce overfitting (see Q1 CAT-2 Set 1 for full detail). Key forms: L1 (Lasso) and L2 (Ridge/Weight Decay).

Dropout

During each training iteration, each neuron is randomly deactivated with probability p (typically 0.5). This forces the network to learn redundant representations and prevents co-adaptation of neurons.

Training: Apply mask m ~ Bernoulli(1-p) → h' = m ⊙ h Inference: Scale weights by (1-p) or use inverted dropout during training. Effect: Equivalent to training an ensemble of 2ⁿ different sub-networks. Reduces over-reliance on any single neuron.
Early Stopping

Monitor validation loss during training. Stop when validation loss starts increasing even though training loss keeps falling. The saved model at the minimum validation loss is returned.

Epoch: 1 2 3 4 5 6 7 8 Train L: 0.9 0.7 0.5 0.3 0.2 0.1 0.05 0.02 Val L: 0.8 0.7 0.6 0.55 0.58 0.65 0.72 0.80 ↑ STOP HERE (epoch 4)

PART B – Gated Recurrent Unit (GRU)
GRU Architecture

GRU is a streamlined version of LSTM with 2 gates (vs LSTM's 3), no separate cell state:

Update gate: zₜ = σ(W_z·[hₜ₋₁, xₜ] + b_z) Reset gate: rₜ = σ(W_r·[hₜ₋₁, xₜ] + b_r) Candidate: h̃ₜ = tanh(W·[rₜ⊙hₜ₋₁, xₜ] + b) New state: hₜ = (1−zₜ)⊙hₜ₋₁ + zₜ⊙h̃ₜ
How GRU Improves Training Stability
  • Update gate decides how much of the past to keep: if zₜ≈0, old memory preserved (like LSTM forget gate); if zₜ≈1, new info replaces it.
  • Reset gate controls how much past context influences the candidate state.
  • The convex combination hₜ = (1−z)⊙h_{t-1} + z⊙h̃ creates a direct gradient path from hₜ to hₜ₋₁ → gradient flows without vanishing.
  • Fewer parameters than LSTM → less prone to overfitting, faster to train.

PART A
Process of Gradient Descent

Gradient Descent is an iterative optimisation algorithm that minimises a loss function J(θ) by moving parameters in the direction of the negative gradient.

Algorithm: 1. Initialise parameters θ randomly (or with small values) 2. Compute loss J(θ) = (1/n)Σ L(ŷᵢ, yᵢ) 3. Compute gradient: ∇J = ∂J/∂θ 4. Update: θ ← θ − η·∇J 5. Repeat until convergence (|ΔJ| < ε) Intuition: Imagine standing on a hilly landscape. The gradient tells you the steepest direction uphill. Moving in the opposite direction takes you towards the valley (minimum loss).

Explain Adam (Adaptive Moment Estimation): first moment, second moment, bias correction, parameter update rule.
10 M
Motivation

Adam combines the advantages of AdaGrad (adapts learning rate per parameter) and RMSProp (uses exponential moving average of squared gradients), plus adds momentum.

Algorithm
Hyperparameters: η=0.001, β₁=0.9, β₂=0.999, ε=10⁻⁸ At each step t with gradient g: 1. First moment estimate (momentum): m_t = β₁·m_{t-1} + (1−β₁)·g [Exponential moving average of gradients → direction] 2. Second moment estimate (adaptive scaling): v_t = β₂·v_{t-1} + (1−β₂)·g² [Exponential moving average of squared gradients → magnitude] 3. Bias correction (compensates for initialisation at 0): m̂_t = m_t / (1−β₁ᵗ) v̂_t = v_t / (1−β₂ᵗ) [At t=1: 1−β₁=0.1, so m̂ = m/0.1 = 10m → unbiased] 4. Parameter update: θ ← θ − η · m̂_t / (√v̂_t + ε)

Why Attention is Needed

In seq2seq models with a fixed encoder context vector, the decoder must compress the entire input sequence into one vector. This bottleneck fails for long sequences — early tokens are forgotten by the time decoding occurs.

Bahdanau Attention Mechanism
Step 1 – Encode

Encode input sequence x₁…xₙ using a bidirectional RNN to produce hidden states h₁…hₙ (each hᵢ = [h→ᵢ; h←ᵢ]).

Step 2 – Alignment Score
eᵢⱼ = score(sⱼ₋₁, hᵢ) = vᵀ·tanh(W₁·sⱼ₋₁ + W₂·hᵢ) where sⱼ₋₁ is the previous decoder hidden state.
Step 3 – Attention Weights (Softmax over scores)
αᵢⱼ = exp(eᵢⱼ) / Σₖ exp(eₖⱼ) [weights sum to 1]
Step 4 – Context Vector
cⱼ = Σᵢ αᵢⱼ·hᵢ [weighted sum of encoder states]

Working of BPTT

BPTT unrolls the RNN across T time steps and applies standard backpropagation on the unrolled graph.

Forward pass: for t = 1 to T: hₜ = tanh(W_hh·h_{t-1} + W_xh·xₜ + b) ŷₜ = softmax(W_hy·hₜ) Lₜ = CrossEntropy(ŷₜ, yₜ) Total loss: L = Σₜ Lₜ Backward pass: for t = T down to 1: δhₜ = ∂L/∂hₜ = W_hyᵀ·δyₜ + W_hhᵀ·δh_{t+1}·diag(1−hₜ²) Gradient of W_hh: ∂L/∂W_hh = Σₜ δhₜ·h_{t-1}ᵀ = Σₜ Σₖ (∂Lₜ/∂hₜ · ∏ᵢ₌ₖᵗ⁻¹ ∂hᵢ₊₁/∂hᵢ) · ∂hₖ/∂W_hh

PART A – VAE Posterior Collapse / Blurry Outputs
Cause

VAE optimises ELBO = E[log p(x|z)] − KL[q(z|x) ‖ p(z)]. When the KL term dominates, the encoder ignores the input and pushes q(z|x) towards the prior → decoder gets no information → blurry outputs.

Fix 1 – KL Annealing (β-scheduling)
Loss = Reconstruction_loss + β·KL_loss Start with β=0 (train decoder first), gradually increase β to 1. → Decoder learns to use latent code before KL penalty kicks in.
Fix 2 – Improved Decoder Capacity / Perceptual Loss
Replace pixel-level MSE with perceptual loss: L_perceptual = ‖φ(x̂) − φ(x)‖² where φ is a pre-trained VGG feature extractor. → Captures high-frequency details, sharper reconstructions. Alternative: Use a convolutional decoder with skip connections (U-Net style).
PART B – GAN for Diverse Facial Expressions
Step 1 – Architecture

Use Conditional GAN (cGAN) or StyleGAN. Condition on expression label (happy, sad, angry, etc.) to ensure diversity.

Step 2 – Diverse Dataset

Collect balanced data across all expressions. Apply augmentation. Use AffectNet or RAF-DB datasets.

Step 3 – Loss Function
L_D = −E[log D(x)] − E[log(1−D(G(z)))] (discriminator) L_G = −E[log D(G(z))] + λ·L_feature_match (generator) Add identity loss: L_id = ‖F(G(z))−F(x_ref)‖ for anonymization
Step 4 – Training Stabilisation

Use Wasserstein GAN (WGAN-GP) with gradient penalty to prevent mode collapse. Apply spectral normalisation to discriminator. Use progressive growing for high-resolution output.

Step 5 – Ensure Diversity

Monitor Fréchet Inception Distance (FID) and Inception Score (IS). If mode collapse detected, increase noise input dimensionality or apply minibatch discrimination.
