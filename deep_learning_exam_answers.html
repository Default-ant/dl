Q1. Regularization, L1 and L2

Regularization is a technique used to reduce overfitting in machine learning and deep learning models. It improves the generalization ability of the model by adding a penalty term to the loss function.

L1 Regularization

L1 regularization adds the absolute values of weights to the loss function.

Formula:

L = Loss + λ Σ|w|

Characteristics:

  • Pushes many weights exactly to zero.
  • Produces sparse models.
  • Acts as a feature selector.
  • Useful when many irrelevant features exist.

L2 Regularization

L2 regularization adds squared weights to the loss function.

Formula:

L = Loss + λ Σw²

  • Reduces magnitude of weights.
  • Prevents very large weights.
  • Improves stability.
  • Does not force weights to exactly zero.

Why L1 Works as Feature Selector

Because the penalty uses absolute values, optimization pushes unimportant weights to exactly zero. Features with zero weights contribute nothing to prediction, effectively removing them.

Q2. CNN Parameter Calculation

Given Architecture

  • Input = 128 × 128 × 3
  • Conv1: 3×3, 32 filters
  • Pool1: 2×2
  • Conv2: 3×3, 64 filters
  • Pool2: 2×2
  • FC1: 256 neurons
  • FC2: 128 neurons

Formula for Convolution Parameters

Parameters = (Kernel Height × Kernel Width × Input Channels + 1 bias) × Number of Filters

Conv1 Parameters

(3×3×3 + 1) × 32 = (27 + 1) × 32 = 896

Conv2 Parameters

(3×3×32 + 1) × 64 = (288 + 1) × 64 = 18,496

Pooling Layers

Pooling layers do not contain trainable parameters.

Fully Connected Layer

Flatten size depends on feature map dimensions after pooling.

Total Parameters

Total = Sum of all convolution and FC parameters.

Transfer Learning

Definition

Transfer learning means using a pre-trained model trained on a large dataset and adapting it to a new task.

Steps

  1. Load pre-trained model.
  2. Freeze early layers.
  3. Replace output layer.
  4. Train on new dataset.
  5. Fine-tune if needed.

Advantages

  • Faster training
  • Higher accuracy
  • Works well with small datasets
  • Reduces computational cost

Batch Normalization

Definition

Batch normalization normalizes activations in each mini-batch.

Formula

x̂ = (x − μ) / √(σ² + ε)

Then:

y = γx̂ + β

Advantages

  • Faster convergence
  • Reduces internal covariate shift
  • Allows larger learning rates
  • Acts as regularizer

RNN – Forward Propagation

RNN Equation

ht = tanh(Wxh xt + Whh ht−1)

Output:

yt = softmax(Why ht)

Steps

  1. Initialize hidden state h0.
  2. Multiply input with Wxh.
  3. Add recurrent contribution Whh·h(t−1).
  4. Apply tanh activation.
  5. Generate output using softmax.

BPTT – Backpropagation Through Time

Definition

BPTT is the training algorithm used for RNNs.

Working

  1. Unroll RNN through time.
  2. Compute forward pass.
  3. Calculate total loss.
  4. Propagate gradients backward through time.
  5. Update weights using gradient descent.

Challenges

  • Vanishing gradients
  • Exploding gradients
  • High computational complexity
  • Long training time

Solutions

  • LSTM
  • GRU
  • Gradient clipping
  • Attention mechanism

LSTM Detailed Answer

Why LSTM?

Traditional RNNs fail to capture long-term dependencies due to vanishing gradients. LSTM introduces gates and memory cells.

Forget Gate

ft = σ(Wf[h(t−1), xt] + bf)

Input Gate

it = σ(Wi[h(t−1), xt] + bi)

Candidate Cell State

C̃t = tanh(Wc[h(t−1), xt] + bc)

Cell State

Ct = ftC(t−1) + itC̃t

Output Gate

ot = σ(Wo[h(t−1), xt] + bo)

Hidden State

ht = ot tanh(Ct)

Advantages

  • Captures long-term dependencies
  • Solves vanishing gradient problem
  • Maintains memory for long sequences

GRU – Gated Recurrent Unit

Definition

GRU is a simplified version of LSTM with fewer gates.

Update Gate

zt = σ(Wz[h(t−1), xt])

Reset Gate

rt = σ(Wr[h(t−1), xt])

Advantages

  • Faster than LSTM
  • Fewer parameters
  • Efficient training

Attention Mechanism

Need for Attention

Encoder-decoder models compress all information into one vector, causing information loss. Attention allows the decoder to focus on important input words.

Bahdanau Attention Steps

  1. Compute alignment scores.
  2. Apply softmax.
  3. Generate attention weights.
  4. Compute context vector.
  5. Generate output.

Advantages

  • Handles long sequences
  • Improves translation quality
  • Focuses on important regions

YOLO Object Detection

Definition

YOLO (You Only Look Once) is a single-stage object detector.

Working

  1. Divide image into grid cells.
  2. Predict bounding boxes.
  3. Predict confidence scores.
  4. Predict class probabilities.
  5. Apply Non-Max Suppression.

Advantages

  • Very fast
  • Real-time detection
  • Single forward pass

GAN – Generative Adversarial Networks

Definition

GAN contains two networks:

  • Generator
  • Discriminator

How GAN Works

  1. Generator creates fake images.
  2. Discriminator checks real or fake.
  3. Both compete during training.
  4. Generator improves progressively.

Improving GAN Performance

  • Use large dataset
  • Data augmentation
  • Batch normalization
  • Feature matching
  • Wasserstein loss
  • Conditional GAN

Adam Optimizer

Definition

Adam combines Momentum and RMSProp.

First Moment

mt = β1m(t−1) + (1−β1)gt

Second Moment

vt = β2v(t−1) + (1−β2)g²t

Bias Correction

m̂t = mt/(1−β1t)

v̂t = vt/(1−β2t)

Parameter Update

θ = θ − α m̂t / (√v̂t + ε)

Advantages

  • Fast convergence
  • Adaptive learning rate
  • Works well on sparse gradients
