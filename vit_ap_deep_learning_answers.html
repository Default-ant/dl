Q2(a) Gradient Descent

Definition: Gradient Descent minimizes the loss function by updating weights opposite to gradient direction.

Formula:

w(new)=w(old)-η(dL/dw)

Steps:

  1. Initialize weights
  2. Perform forward propagation
  3. Calculate error
  4. Compute gradients
  5. Update weights
  6. Repeat until convergence

Q2(b) Types of Gradient Descent
