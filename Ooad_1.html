📁 Pillar 1: Things (UML Vocabulary)

Things are the primary architectural abstractions and first-class citizens used to populate system blueprints. They represent the static nouns, dynamic verbs, organizational units, and explanatory context of a design model.

Structural Things

Static nouns modeling conceptual or physical layouts.

  • Class: Set of objects sharing attributes and operations.
  • Interface: Non-implemented public service contract.
  • Use Case: Sequence of goal-driven system actions.
  • Component: Modular, physical execution block.
  • Node: Computational hardware environment.
  • Collaboration: Cooperative pattern of roles.
  • Active Class: Class owning concurrent threads.
  • Artifact: Physical file (e.g., jar, dll) deployed to a Node.

Behavioral Things

Dynamic verbs representing pathways and state shifts.

  • Interaction: Chronological messages passed among lifelines.
  • State Machine: Specification tracking an object's discrete transitions over time.

Grouping & Annotational

Modularity containers and descriptive remark units.

  • Package: Organizational mechanism to build distinct namespaces.
  • Note: Visually attached textual comments or constraints.

💡 The Four Principles of Modeling

These core tenets dictate how software-intensive systems should be systematically analyzed, abstracted, and constructed.

Principle 1: Choice of Model Impact

The choice of what models to create has a profound influence on how a problem is attacked and how a solution is shaped. Algorithmic vs. Object-Oriented styles produce completely different visual worlds.

Principle 2: Flexible Precision

Every model may be expressed at different levels of precision. High-level maps align business stakeholders, while detailed specifications guide coders with exact attribute and signature details.

Principle 3: Grounded in Reality

The best models are connected to reality. Simplified abstractions must preserve direct traceability and mapping to concrete, compilable execution classes, databases, and physical architectures.

Principle 4: No Single Model is Sufficient

No single model is sufficient. Complex systems must be viewed through distinct, independent dimensions (e.g., the 5-View Architecture: Use Case, Design, Process, Implementation, and Deployment views).

1.2Probability Basics for Deep Learning

Random Variable

Variable whose value is determined by a random experiment. Discrete or continuous.

Probability Distribution

Describes likelihood of outcomes. P(X=x) ≥ 0, ΣP = 1

Gaussian / Normal

p(x) = (1/√2πσ²) exp(−(x−μ)²/2σ²). Used in weight init, noise, VAEs.

Bernoulli

Binary outcome. P(X=1)=p, P(X=0)=1−p. Used in dropout.

Softmax: P(yᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ) ← converts scores to probabilities (sum=1) Cross-Entropy Loss: L = −Σᵢ yᵢ log(ŷᵢ) ← measures distribution difference KL Divergence: D_KL(P‖Q) = Σᵢ P(i) log(P(i)/Q(i)) ← used in VAE
1.3Gradient-Based Optimization
Gradient: Vector of partial derivatives ∇J(θ). Points in direction of steepest ascent. We move in the negative direction to minimise J.
Gradient Descent update rule: θ ← θ − η · ∇J(θ) where η = learning rate (step size), ∇J = gradient of loss w.r.t. parameters Chain Rule (essential for backpropagation): If z = f(g(x)) → dz/dx = (dz/dg) · (dg/dx)

Linear Regression

Model: ŷ = Wx + b Loss: J = (1/n)Σ(ŷᵢ − yᵢ)² (MSE) Update: W ← W − η·(∂J/∂W) = W − η·(2/n)Σ(ŷᵢ−yᵢ)·xᵢ

Logistic Regression

Model: ŷ = σ(Wx + b) = 1/(1 + e^{−(Wx+b)}) Loss: J = −(1/n)Σ[yᵢlog(ŷᵢ) + (1−yᵢ)log(1−ŷᵢ)] (Binary Cross-Entropy) Predict: class = 1 if ŷ > 0.5 else 0

1.4Introduction to Neural Networks
A Neural Network is a directed acyclic graph of interconnected neurons. Each connection has a weight. Each neuron computes a weighted sum of its inputs, adds a bias, and applies an activation function.

Perceptron

Single neuron: output = f(Σᵢ wᵢxᵢ + b) Learning rule: wᵢ ← wᵢ + η·(target − output)·xᵢ b ← b + η·(target − output) Threshold activation: output = 1 if net ≥ θ, else 0

Multi-Layer Perceptron (MLP)

  • Input layer → one or more hidden layers → output layer
  • Each layer is a linear transformation followed by non-linear activation
  • Can approximate any continuous function (Universal Approximation Theorem)
  • Trained via backpropagation

Layers1 (input + output)Input + ≥1 hidden + output
ActivationStep functionSigmoid, ReLU, tanh
LearningPerceptron ruleBackprop + GD

2.2Backpropagation Algorithm
Backpropagation = Efficiently compute gradients of the loss w.r.t. all parameters using the chain rule, propagating error backwards from output to input.

Algorithm (sigmoid activation, MSE loss)

FORWARD PASS: net_j = Σᵢ wᵢⱼ·xᵢ + bⱼ out_j = sigmoid(net_j) = 1/(1+e^{−net_j}) BACKWARD PASS (Output layer): δⱼ = (target_j − out_j) · out_j · (1 − out_j) ← error signal BACKWARD PASS (Hidden layer): δⱼ = out_j·(1−out_j) · Σₖ (δₖ · wⱼₖ) ← propagated error WEIGHT UPDATE: Δwᵢⱼ = η · δⱼ · out_i wᵢⱼ_new = wᵢⱼ_old + Δwᵢⱼ Δbⱼ = η · δⱼ bⱼ_new = bⱼ_old + Δbⱼ
📌
For MSE loss L=½Σ(t−o)², the output delta formula uses (t−o) with the derivative of activation. For cross-entropy + softmax, the delta simplifies to (ŷ−y).

2.3Regularization for Deep Learning
Regularization = Adding a penalty to the loss function to reduce model complexity and prevent overfitting.

L1 vs L2 Regularization

L1 (Lasso): L_reg = L + λΣ|wᵢ| Gradient: sign(wᵢ) → weights can go exactly to ZERO → feature selection L2 (Ridge): L_reg = L + λΣwᵢ² Gradient: 2λwᵢ → weights shrink but stay non-zero → weight decay Key difference: L1 constraint = diamond (corners on axes) → hits sparse solutions L2 constraint = sphere (smooth) → distributes weight reduction evenly L1 acts as automatic FEATURE SELECTOR because it drives irrelevant weights to exactly 0

Dropout

During training: randomly deactivate each neuron with probability p Mask: m ~ Bernoulli(1−p) → h' = m ⊙ h During inference: scale weights by (1−p) [or use inverted dropout during training] Effect: trains ensemble of 2^n sub-networks

Other Techniques

TechniqueMechanismWhen to Use
Early StoppingStop when validation loss increasesAlways monitor val loss
Data AugmentationFlip, rotate, crop, noise additionSmall image datasets
Batch NormalizationNormalize activations per mini-batchDeep CNNs, faster training
Weight DecaySame as L2 regularizationAll deep networks

Adam (Adaptive Moment Estimation) – Full Derivation

Hyperparameters: η=0.001, β₁=0.9, β₂=0.999, ε=10⁻⁸ Step 1 – First moment (momentum): m_t = β₁·m_{t-1} + (1−β₁)·g_t Step 2 – Second moment (adaptive scaling): v_t = β₂·v_{t-1} + (1−β₂)·g_t² Step 3 – Bias correction (corrects initialisation at 0): m̂_t = m_t / (1 − β₁^t) v̂_t = v_t / (1 − β₂^t) Step 4 – Parameter update: θ_t = θ_{t-1} − η · m̂_t / (√v̂_t + ε) Interpretation: m̂_t = smoothed gradient direction (like momentum) v̂_t = smoothed squared gradient magnitude (like RMSProp) Together → large steps in low-curvature directions, small steps in high-curvature

3.1Convolutional & Pooling Layers

Convolution Operation

Output size (conv): out = floor((in + 2p − k) / s) + 1 where: in = input size, p = padding, k = kernel size, s = stride Padding types: 'same' (p = (k−1)/2): output size = input size 'valid' (p = 0): output size = in − k + 1 Learnable parameters (one conv layer): params = (k × k × C_in + 1) × C_out (+1 for bias per filter) Examples: 3×3 conv, 1 input ch, 32 filters: (3×3×1+1)×32 = 10×32 = 320 3×3 conv, 32 → 64 filters: (3×3×32+1)×64 = 289×64 = 18,496

Pooling

Max Pooling: output = max value in each window Average Pooling: output = mean value in each window Global Avg Pool: output = mean of entire feature map → single scalar per channel Output size same formula: floor((in − k)/s) + 1 Pooling has ZERO learnable parameters.

Full CNN Parameter Count

For each layer: Conv: (k×k×C_in+1)×C_out ← learnable Pool: 0 ← no params FC: (n_in + 1) × n_out ← learnable (n_in includes all spatial dimensions) FC after last pool: n_in = H_out × W_out × C_out

Inception Block (GoogLeNet)

Input: W×H×C 4 parallel branches (same padding → same spatial output): Branch 1: 1×1 conv (64 filters) Branch 2: 1×1 conv (96) → 3×3 conv (128) Branch 3: 1×1 conv (16) → 5×5 conv (32) Branch 4: 3×3 max-pool → 1×1 conv (32) Output: concatenate all branches along depth dimension Total depth = 64 + 128 + 32 + 32 = 256 channels 1×1 conv purpose: dimensionality reduction before expensive 3×3/5×5 convs → saves computation

ResNet Skip Connection

Standard: a⁽ˡ⁺¹⁾ = f(W⁽ˡ⁾·a⁽ˡ⁾ + b⁽ˡ⁾) Residual: a⁽ˡ⁺²⁾ = f(F(a⁽ˡ⁾) + a⁽ˡ⁾) where F = 2-layer transform Gradient through skip: ∂L/∂a⁽ˡ⁾ = ∂L/∂a⁽ˡ⁺²⁾ · (∂F/∂a⁽ˡ⁾ + I) → Identity term I ensures gradient ≥ 1 → NO vanishing gradient

3.4Batch Normalization & Dropout in CNNs
Batch Normalization (for mini-batch B = {x₁,...,xₘ}): Step 1: μ_B = (1/m)Σxᵢ ← batch mean Step 2: σ²_B = (1/m)Σ(xᵢ − μ_B)² ← batch variance Step 3: x̂ᵢ = (xᵢ − μ_B) / √(σ²_B + ε) ← normalize Step 4: yᵢ = γ·x̂ᵢ + β ← scale & shift (γ, β are LEARNED) Why it helps: 1. Reduces internal covariate shift 2. Allows higher learning rates → faster convergence 3. Acts as implicit regularizer 4. Smoothes loss landscape

4.1RNN & Backpropagation Through Time (BPTT)
RNN: A neural network with recurrent (self-loop) connections that allows it to maintain a hidden state, enabling sequential/temporal processing.
Forward pass: hₜ = tanh(W_xh·xₜ + W_hh·h_{t-1} + b_h) ŷₜ = softmax(W_hy·hₜ + b_y) BPTT – Gradient through time: ∂L/∂W_hh = Σₜ Σₖ≤t ∂Lₜ/∂hₜ · (∏ᵢ₌ₖᵗ⁻¹ ∂hᵢ₊₁/∂hᵢ) · ∂hₖ/∂W_hh Product term: ∏ diag(1−hᵢ²) → 0 if many steps → vanishing gradient or → ∞ → exploding gradient

4.2Long Short-Term Memory (LSTM)
LSTM: A gated RNN cell with an explicit cell state that acts as a memory highway. Uses three gates (forget, input, output) to selectively remember and forget information.
Combined input: z = [xₜ; h_{t-1}] (concatenation) Forget gate: fₜ = σ(Wf·z + bf) ← what to erase from cell state Input gate: iₜ = σ(Wi·z + bi) ← what new info to write Cell candidate: g̃ₜ = tanh(Wc·z + bc) ← candidate values to write Cell state: cₜ = fₜ⊙c_{t-1} + iₜ⊙g̃ₜ ← memory update (KEY!) Output gate: oₜ = σ(Wo·z + bo) ← what to output Hidden state: hₜ = oₜ⊙tanh(cₜ) Gradient through cell: ∂cₜ/∂c_{t-1} = fₜ (element-wise) → When fₜ ≈ 1, gradient flows freely → NO vanishing gradient!

Why LSTM > RNN

Cell State Highway

cₜ passes through time with only element-wise multiplication (by fₜ), no repeated matrix multiplication → stable gradient.

Gated Memory

Forget gate can set fₜ≈1 for long-term memory and fₜ≈0 for short-term. Enables learning both short and long dependencies.

Selective Writing

Input gate iₜ and cell candidate g̃ₜ control what new info enters the cell state. Not everything is blindly stored.

Selective Reading

Output gate oₜ controls how much of the cell state to expose as the hidden state at each step.

4.3Gated Recurrent Unit (GRU)
GRU: Simplified version of LSTM with 2 gates (update + reset) and no separate cell state. Fewer parameters, similar performance.

4.4Bidirectional RNN & Bi-LSTM
Bidirectional RNN/LSTM: Processes the sequence in both forward and backward directions, concatenating hidden states. Each position has context from both past AND future tokens.
Forward LSTM: h→ₜ processes x₁ → x₂ → ... → xₙ Backward LSTM: h←ₜ processes xₙ → xₙ₋₁ → ... → x₁ Output: ŷₜ = W·[h→ₜ ; h←ₜ] + b (concatenation) Use case: Speech-to-text, named entity recognition, machine translation. "The bank can guarantee deposits will eventually cover future tuition costs" → "bank" needs future context to determine meaning (financial or river?)

Why Bi-LSTM outperforms Bi-RNN for long sequences

  • Bi-RNN suffers vanishing gradients → early tokens get near-zero gradient
  • LSTM's cell state preserves information over long distances
  • Bidirectional pass provides full sequence context at every position

5.1Encoder-Decoder Models
Encoder-Decoder: The encoder compresses input into a fixed-size context vector (latent representation). The decoder generates output from this context vector.

Encoder

Reads entire input sequence, produces context vector C = h_T (final hidden state).

Context Vector

Fixed-length bottleneck. Information bottleneck problem: long sequences compressed into one vector.

Decoder

Generates output token by token, conditioned on context vector and previously generated tokens.

Limitation

Fixed context vector cannot capture all information from long sequences → attention mechanism needed.

U-Net (for segmentation)

Encoder-decoder with skip connections between corresponding encoder and decoder layers. Preserves spatial information lost during downsampling. Used in medical image segmentation.

5.2Attention Mechanism (Bahdanau)
Attention: Instead of a single context vector, compute a dynamic weighted sum of all encoder hidden states for each decoder step. The model learns which encoder positions to "attend" to.

Bahdanau Attention Steps

Step 1 – Encode: Run bidirectional RNN on x₁...xₙ → hidden states h₁,...,hₙ Step 2 – Alignment score: eᵢⱼ = vᵀ·tanh(W₁·sⱼ₋₁ + W₂·hᵢ) where sⱼ₋₁ = previous decoder state Step 3 – Attention weights (softmax): αᵢⱼ = exp(eᵢⱼ) / Σₖ exp(eₖⱼ) ← sum = 1 Step 4 – Context vector: cⱼ = Σᵢ αᵢⱼ·hᵢ ← dynamic, decoder-step-specific Step 5 – Decode: sⱼ = f(sⱼ₋₁, yⱼ₋₁, cⱼ) P(yⱼ|yKey advantage: no information bottleneck. Each output position can directly access any input position.

6.1Autoencoders
Autoencoder: Unsupervised network trained to reconstruct its input. Encoder compresses input to latent space z; decoder reconstructs from z. Forces learning of compact representations.
Encoder: z = f_enc(x; θ_enc) ← compress Decoder: x̂ = f_dec(z; θ_dec) ← reconstruct Loss: L = ‖x − x̂‖² ← reconstruction error (MSE) Types: Undercomplete: dim(z) < dim(x) → learns compressed representation Sparse: regularise z to be sparse → forces few active neurons Denoising: input = corrupted x, target = clean x → learns denoising Variational: adds probabilistic latent space (VAE)
6.2Variational Autoencoder (VAE)
VAE: A generative model where the encoder outputs parameters of a distribution (μ, σ) rather than a single point. Samples z ~ N(μ, σ²). Enables generation of new data by sampling from the prior.
Encoder: q_φ(z|x) = N(μ_φ(x), σ_φ(x)²) ← outputs μ, σ (not z directly) Reparameterisation trick: z = μ + σ·ε where ε ~ N(0, I) ← makes sampling differentiable Decoder: p_θ(x|z) ← generate x from z ELBO loss (to maximise): ELBO = E[log p_θ(x|z)] − KL[q_φ(z|x) ‖ p(z)] Term 1 (reconstruction): E[log p(x|z)] → MSE or BCE loss Term 2 (regularisation): KL divergence → pushes q(z|x) towards N(0,I) Generation: sample z ~ N(0,I), decode → new image

VAE Problems & Solutions

ProblemCauseFix
Blurry outputsMSE loss penalises all pixel differences equallyPerceptual loss (VGG features), adversarial loss (VAE-GAN)
Posterior collapseKL dominates → encoder ignores inputKL annealing (β schedule: start β=0, increase to 1)
Limited diversityUnimodal prior N(0,I)Mixture of Gaussians prior, VQ-VAE

6.3Generative Adversarial Networks (GAN)
GAN: Two networks trained adversarially. Generator G tries to fool the Discriminator D. D tries to distinguish real from fake. At Nash equilibrium, G generates indistinguishable data.
Minimax objective: min_G max_D V(D,G) = E[log D(x)] + E[log(1−D(G(z)))] Discriminator loss: L_D = −E[log D(x)] − E[log(1−D(G(z)))] ← maximise Generator loss: L_G = −E[log D(G(z))] ← minimise Training alternation: Step 1: Fix G, train D for k steps Step 2: Fix D, train G for 1 step Repeat

GAN Problems & Solutions

ProblemDescriptionSolution
Mode CollapseG maps all z to same output → no diversityWGAN-GP, minibatch discrimination, increased noise
Training InstabilityG and D go out of sync; oscillationWGAN (Wasserstein distance), spectral normalisation, careful LR
Non-convergenceD becomes too good → G gets zero gradientLabel smoothing, add noise to D inputs, balance training
Vanishing gradient for Glog(1−D(G(z))) → saturatedUse −log D(G(z)) instead (non-saturating GAN)

GAN Variants

DCGAN

Deep Convolutional GAN. Uses transpose convolutions in G, strided convolutions in D. No FC layers. BatchNorm. LeakyReLU in D.

cGAN (Conditional GAN)

Generator and discriminator both conditioned on class label y. Allows targeted generation: generate face with "happy" expression.

CycleGAN

Unpaired image-to-image translation. Two generators, two discriminators. Cycle consistency loss ensures X→Y→X = X.

StyleGAN

Style-based generator. Separate style codes control different scales of features (coarse: pose, fine: hair texture). State-of-art for faces.

WGAN-GP

Wasserstein distance + gradient penalty. Stable training, meaningful loss metric. Critic (not discriminator) trained multiple times per G step.

Evaluation Metrics

FID (Fréchet Inception Distance): lower = better quality + diversity. IS (Inception Score): higher = better. Used to compare GANs.

Steps to Build GAN for Face Generation (Identity Anonymisation)

1. Architecture: Use DCGAN or StyleGAN backbone. For diverse expressions → add conditional input (expression label) 2. Dataset: Collect balanced data across all expression classes. Apply augmentation to underrepresented expressions. 3. Loss functions: L_D = BCE(D(x), 1) + BCE(D(G(z)), 0) + λ·GP ← gradient penalty for stability L_G = BCE(D(G(z)), 1) + λ_id·L_identity ← identity preservation L_id = ‖face_encoder(G(z)) − face_encoder(x_ref)‖ ← anonymisation constraint 4. Training: Alternate D and G updates. Monitor FID every N iterations. Use spectral normalisation on D. Progressive growing from 4×4 to target. 5. Diversity check: If mode collapse detected: → Add minibatch discrimination to D → Increase latent dimension → Use WGAN-GP
