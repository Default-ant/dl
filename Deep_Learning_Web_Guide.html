Module 2: Regularization & Optimization

1. Regularization (Preventing Overfitting)

Overfitting occurs when a model learns noise and memorizes training data, performing poorly on unseen data. Regularization introduces constraints to prevent this.

  • L1 Regularization (Lasso): Adds the absolute value of weights to the loss. Formula: \( Loss = Original + \lambda \sum |w| \). Forces weights to zero, creating sparse models. Acts as a feature selector.
  • L2 Regularization (Ridge): Adds squared value of weights. Formula: \( Loss = Original + \lambda \sum w^2 \). Distributes weights evenly and prevents them from becoming too large.
  • Dropout: Randomly disables a fraction of neurons (e.g., 50%) during training. Prevents co-dependency among neurons and forces the model to learn robust, general patterns.
  • Early Stopping: Training is halted when validation loss stops decreasing, preventing the model from over-training on noise.
  • Batch Normalization: Normalizes inputs of each layer during training on mini-batches. Stabilizes learning, speeds up convergence, and acts as a weak regularizer.

2. Optimization Algorithms

Optimization adjusts weights and biases to minimize the loss function.

  • Batch Gradient Descent: Uses the entire dataset for one update. Stable but very slow for large data.
  • Stochastic Gradient Descent (SGD): Updates weights using one example at a time. Fast, escapes local minima, but has noisy updates.
  • Mini-Batch Gradient Descent: The standard approach. Uses batches (e.g., 32, 64). Balances speed and stability.
  • Momentum: Adds a fraction of the previous update to the current one, accelerating convergence and reducing oscillation.
  • Adam (Adaptive Moment Estimation): Combines Momentum and RMSProp. Adapts learning rates for each parameter. The most widely used optimizer in deep learning.

Module 3: CNN Architectures & Transfer Learning

1. CNN Core Components

  • Convolutional Layer: Extracts features using filters/kernels.
  • Activation (ReLU): Adds non-linearity, converting negatives to zero.
  • Pooling (Max/Average): Downsamples feature maps, reducing dimensions and computation.

Crucial CNN Formulas

Output Spatial Dimension: \( ext{Output Size} = \lfloor rac{W - F + 2P}{S} floor + 1 \)

Where W = Input size, F = Filter size, P = Padding, S = Stride.

Trainable Parameters: \( ext{Params} = (F imes F imes C_{in} imes C_{out}) + C_{out} \)

Where \(C_{in}\) = Input channels, \(C_{out}\) = Number of filters.

2. Popular Architectures

  • AlexNet: Won ImageNet 2012. Introduced ReLU, Dropout, and Data Augmentation.
  • VGG16/19: Uses only 3x3 filters. Deep but heavy on parameters (~138M).
  • GoogLeNet (Inception): Uses parallel convolutions (1x1, 3x3, 5x5) and Global Average Pooling to drastically reduce parameters.
  • ResNet: Uses skip connections to solve the vanishing gradient problem, enabling networks with 100+ layers.

3. Transfer Learning

Reusing pre-trained models (like VGG trained on ImageNet) for new tasks.

  • Feature Extraction: Freeze all pre-trained layers. Use them only to extract features and train a new, fresh classification layer at the end. Best when the new dataset is small.
  • Fine-Tuning: Unfreeze the top layers of the pre-trained model and train them alongside the classifier with a very small learning rate. Best when you have a larger dataset.

Module 4: RNNs, LSTM, GRU & Sequence Models

1. Backpropagation Through Time (BPTT)

Unrolls the RNN across time steps to compute gradients. Suffers heavily from Vanishing and Exploding Gradients on long sequences.

RNN Formulas (Essential for Problems)

Hidden State: \( h_t = anh(W_{xh}x_t + W_{hh}h_{t-1} + b_h) \)

Logits: \( z_t = W_{hy}h_t + b_y \)

Softmax Output: \( \hat{y}_t = rac{e^{z_i}}{\sum e^{z_j}} \)

2. Comparisons of Sequence Models

Architecture Characteristics
RNN Basic memory loop. Fails to remember long-term context due to vanishing gradients.
LSTM (Long Short-Term Memory) Solves vanishing gradients. Has 3 gates (Input, Forget, Output) and a separate Cell State (\(C_t\)) to carry long-term memory. Highly accurate but computationally expensive.
GRU (Gated Recurrent Unit) Simpler than LSTM. Has only 2 gates (Update, Reset) and merges the cell state into the hidden state. Faster to train and requires fewer parameters.
Bi-RNN vs Bi-LSTM Both process data forwards and backwards. Bi-RNN still suffers from short memory. Bi-LSTM retains long-term bidirectional context (e.g., understanding a word based on the end of the sentence).

Modules 5 & 6: Attention, YOLO, GANs & VAEs

  • Attention Mechanism (Bahdanau): Solves the bottleneck of standard Encoder-Decoder models. Instead of squashing a whole sentence into one vector, it allows the decoder to "pay attention" to different parts of the input sequence dynamically while generating each word.
  • YOLO (Single-Pass) vs R-CNN (Two-Stage): Traditional R-CNN proposes thousands of regions and classifies them sequentially (slow). YOLO (You Only Look Once) divides the image into a grid and predicts bounding boxes and classes simultaneously in a single forward pass (extremely fast, real-time).
  • VAEs (Variational Autoencoders): Generative models that learn the underlying probability distribution of data to generate new, diverse samples.
  • GANs (Generative Adversarial Networks): Consists of a Generator (creates fake images) and a Discriminator (tries to catch fakes). They compete until the Generator produces hyper-realistic images.

F1 Slot FAT Paper (May 2026) Solutions

Q3 (b) Feature Extraction vs Fine-Tuning

Feature Extraction: We freeze the convolutional base of a pre-trained model and only train a new fully connected layer. Use this when the new dataset is small and similar to the original dataset (e.g., ImageNet) to prevent overfitting.

Fine-Tuning: We unfreeze the top convolutional layers and train them along with the classifier using a very low learning rate. Use this when the new dataset is large, allowing the model to adapt its feature extraction to the new specific domain without overfitting.

Q3 (b) Role of Normalization

Normalization scales inputs to a standard range (e.g., 0 to 1). Batch Normalization specifically normalizes activations between layers. It improves training stability by reducing internal covariate shift, allowing the use of higher learning rates, which drastically improves convergence speed.

Q5. Bi-LSTM vs Bi-RNN & GRU

(a) Bi-LSTM vs Bi-RNN: Both process sequences in forward and backward directions to capture past and future context. However, Bi-RNN uses simple recurrent units and suffers from the vanishing gradient problem, meaning it cannot capture long-term dependencies. Bi-LSTM uses memory cells and three gates (Input, Forget, Output) to effectively store and retrieve information over long sequences, making it vastly superior for complex sequence data.

(b) GRU Working Mechanism: The Gated Recurrent Unit uses only two gates: an Update Gate (decides how much past information to keep) and a Reset Gate (decides how much to forget). Unlike LSTM, it does not have a separate cell state; it merges memory into the hidden state. This simpler architecture improves training stability and speed compared to standard RNNs while avoiding vanishing gradients.

Q1. L1 Regularization as a Feature Selector

L1 Regularization adds the absolute value of the weights to the loss function. Because of the geometry of the absolute value penalty (creating sharp corners in the loss landscape), gradient descent naturally pushes the weights of less important features exactly to zero. By zeroing out useless weights, L1 effectively performs automatic feature selection, resulting in a sparse, highly interpretable model.
